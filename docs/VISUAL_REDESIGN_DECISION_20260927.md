# 視覺改版核定 — 2026-09-27

使用者檢視本機預覽後指出：「你有用 apple Design 審查過嗎，我感覺設計沒變啊。」

已說明先前 Apple Design 審查主要改善可用性與無障礙，沒有完成整體視覺改版；先前稱「新版設計」不夠準確。

使用者明確選擇：**明顯重新設計：簡潔留白、清楚層級、重整首頁與案件頁**。

## 執行範圍

- 重整首頁、案件列表、案件詳細頁及共用導覽的資訊層級與視覺。
- 減少零碎卡片、雜色與重複標示，使用清楚的字级、間距、分區與操作入口。
- 保留原有業務規則、資料、權限、單一案件多報價、待配對提示和無障礙操作。
- 實作採 frontend skill；完成後由不同 agent 依指定 Apple Design skill 獨立審查。
- 保留前後畫面與實測紀錄；不將單純功能更新說成完整視覺改版。

截至本紀錄建立，仍在本機實作，未部署此次視覺改版。
